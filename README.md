# CS193 Soccer Referee Assistant

A Java Program that helps Soccer Referees practice basic fundamental skills to be better.

## The Problem

Whenever I observe amateur soccer referees they don't always know what they're doing. For example, at my little brother's soccer games the ref will get caught not knowing which call to give. This situation always gets me thinking what I can do to make it easier for them to officiate.

## How It Works

A program that has a menu which leads to all the different screens needed. For instance, Rules screen which has all the guides and rules for the user to read and memorize. Next, the Practice Screen that gives user Scenarios and lets them practice their skills. Next, Quiz screen which lets the user test their knowledge. Lastly, the progress screen that lets the user see their progress through the quiz scores.

## Tech Stack

- **Language:** Java.
- **Libraries:** Java libraries like Scanner and ArrayList.
- **External tools:** No API's but store data in txt files.
